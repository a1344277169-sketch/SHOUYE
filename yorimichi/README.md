# よりみち / 走错了，谢谢

白底与橙色的日文手机网页原型，可添加到手机主屏幕，以独立窗口体验。

## 打开

部署此仓库的静态网站后访问 /yorimichi/。不需要安装依赖或构建。
本目录独立于个人网站首页，不修改其他目录。

## 可操作内容

- 发现页、论坛分类、关键词搜索、帖子详情
- 点赞、收藏；分享、地区切换和设置显示“工事中”提示
- 添加评论、创建本机投稿，可选上传 700KB 以下照片
- 将地点加入回程、自动计算经过所有所选地点的最短路线、移除地点、查看步行顺序
- 保存列表、个人投稿列表、删除自己的投稿
- manifest 与 Service Worker；支持的浏览器可添加到主屏幕
- 小屏全宽显示，桌面以手机画布展示

## 原型范围

这是一份策划演示原型，不含共享后端、账号系统、实时 GPS 或真实路径计算。
样例人物、地点、徒歩时间和故事均为演示数据。地图为示意图，不用于实际导航。
帖子、评论、点赞、收藏、回程仅保存在当前浏览器的 localStorage 中，不会跨设备同步或向其他访客发布。
帖子只在当前浏览器内保存；当前分享入口显示暂未开放。
照片为场景素材，并非所述虚构商家的实景。新增投稿应避免上传个人敏感信息。

## 文件

index.html 页面入口
app.css 页面样式
app.js 路由、交互与浏览器内存储
manifest.webmanifest 主屏幕应用信息
sw.js 离线静态资源缓存（不缓存其他项目资源）
icon.svg 应用图标

## 开发与验证

通过任意静态 HTTP 服务预览即可，例如 node 的静态服务或 python -m http.server。
建议在 390px、430px 与桌面宽度检查，验证：
收藏跨刷新保存；以不同顺序添加地点并确认路线一致、移除回程地点；创建本机帖子并评论；搜索；空状态；弹窗限制在手机容器内。
