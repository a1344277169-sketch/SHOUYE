# となり便り / 跨世代交流 App 示意网站

无需安装依赖的手机 App 动态展示网站。桌面端参考「よりみち」：左侧功能说明、右侧固定手机画面；手机端直接显示全屏 App。打开 index.html，或使用任意静态服务器预览。

## 功能
- 六个人设：长者和子、しげる、千代；年轻人美咲、はる、蓮。千代为福冈的前花店店主，蓮为京都的大学院生，沿用原有小人头像。
- 每种心情有独立的匹配人选、开场白与推荐理由；重复匹配或点“ほかのお相手も見る”会轮换结果。进入私聊时延续所选心情和匹配回应。
- 手机框内的页面切换过渡、弹窗动效、漂流瓶轻微浮动。
- 约 45 秒自动演示：论坛、长者与年轻人心情、匹配、私聊、漂流瓶、视频连线；可随时停止和手动操作。
- 五个主入口按“漂流瓶、广场、心情匹配、私聊、视频连线”排列。
- 视频连线：选择朋友、邀请、接通演示、静音与摄像头开关、结束与继续私聊。用已有小人展示画面，不访问摄像头、麦克风，不连接真人。
- 品牌图标为老少同框圆形 Logo。视频取景采用同款 IP 半身表情素材，循环显示说话、眨眼和招手，保留对方大画面和自己的小画面。
- 切换年轻人和长者视角，字号、问候、心情选项、联系人随身份改变。
- 生活论坛：分类筛选、发帖演示、回应、收藏、语音界面。
- 心情摇人：不同身份的意愿选项、文字/语音偏好、示例伙伴和邀请演示。
- 跨代漂流瓶：拾取、回复、收藏、投递、自己的瓶子。
- 好友聊天：联系人、对话详情、文字发送演示、语音留言入口。
- 头像沿用项目原有老爷爷、和子、美咲、年轻男性小人；点击统一提示个人主页未开放。

所有人物、消息及匹配结果均为示例，交互只发生在本浏览器，不连接真人、不上传内容。演示内容在刷新后重置。语音入口展示文字摘要，真实录音和实时通话未开放。

## 文件
index.html、style.css、app.js、personas.js、video.js、showcase.css、showcase.js、assets/ 为部署文件。可部署到 GitHub Pages、Cloudflare Pages 等静态托管，支持子目录，无构建步骤。
